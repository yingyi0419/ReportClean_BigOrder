完整可執行的 Vite + React 專案。每次只要上傳或拖曳最新版 Excel，系統會重新執行資料診斷、清理、成功拜訪判斷、四層績效分析、明細檢視及 Excel 匯出，不需修改路徑或重新部署。

## 功能

- 真實解析 `.xlsx`／`.xls`，不使用假資料。
- 自動尋找明細工作表；符合欄位時優先使用 `all`。
- 成功拜訪固定依 `訂餐日期 > 電訪日期` 嚴格判斷。
- 區域、AC、餐廳、電訪人員四層階層分析。
- 日期、區域、AC、餐廳與成功狀態互動篩選。
- 每週趨勢、區域成功率、客戶類型與轉換漏斗。
- 明細搜尋、分頁及隱私欄位保護。
- 診斷重複、日期、金額、狀態與來源成功判斷差異。
- 匯出分析摘要、篩選明細／完整清理資料與診斷。
- 內建 GitHub Pages 自動部署流程。

## VS Code 執行

需要 Node.js 22 以上版本。

```bash
npm install
npm run dev
```

終端機通常會顯示 `http://localhost:5173`。

## 驗證

```bash
npm test
npm run validate:workbook -- "●大單拜訪表_all_ v3.xlsx"
npm run build:static
```

## GitHub Pages

1. 將整個專案上傳至 GitHub Repository，預設分支使用 `main`。
2. 到 `Settings → Pages`。
3. `Source` 選擇 `GitHub Actions`。
4. 推送到 `main` 後會自動發布。
5. 後續更新 Excel 時不用再推送或部署，直接在網站上傳新版檔案。

## 來源檔基準檢核

使用 `●大單拜訪表_all_ v3(1).xlsx` 驗證：

- 採用工作表：`all`
- 原始明細：4,096 筆
- 電訪日期：2026-01-08～2026-07-26
- 成功拜訪：850 筆
- 成功消費金額：NT$4,195,451
- 成功但缺少消費金額：5 筆
- 疑似重複：1 筆
- 來源成功欄與系統重算差異：0 筆

預設勾選「排除疑似重複」，因此畫面有效拜訪為 4,095 筆；成功筆數與金額不受該筆影響。
